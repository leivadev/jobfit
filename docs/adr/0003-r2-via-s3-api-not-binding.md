# R2 accessed via S3-compatible API (boto3), not a Workers binding

R2's native binding (`env.BUCKET.get(...)`) only works inside the Cloudflare Workers runtime. The backend is a Python FastAPI service with heavy ML dependencies (torch, faiss-cpu, sentence-transformers) running on Azure Container Apps — it is not, and cannot be, a Worker. So the backend reads Artifacts from R2 using `boto3` against R2's S3-compatible endpoint with an API token, not the binding. Anyone tempted to "just use the binding" from backend code should know it's not an oversight: it's structurally unavailable outside the Workers runtime.
