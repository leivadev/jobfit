# Explicit CORS whitelist, not a same-origin proxy

Frontend (`jobfit-app.leivadev.com`, Cloudflare Workers) and backend (`jobfit-api.leivadev.com`, Azure Container Apps) are different origins even though both are subdomains of a domain we own — owning the domain doesn't remove CORS. We considered having the Worker proxy `/api/*` requests to the backend under a single origin, which would eliminate CORS entirely and hide the backend URL. We rejected it for the MVP: it adds a request hop and a piece of infrastructure to maintain for a problem (CORS) that's fully solved by a one-line origin whitelist in FastAPI. The proxy stays on the table as a future option, not a gap.
